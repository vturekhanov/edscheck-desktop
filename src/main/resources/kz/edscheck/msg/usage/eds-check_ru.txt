eds-check (Java) — проверка ЭЦП в CMS-контейнере (CAdES) или detached-подписи

использование: eds-check [опции] <CONTAINER>

  CONTAINER               путь к CMS-файлу или '-' (stdin)
  --ca УЦ                 auto (по умолчанию), nca, btsd, ucgo, fake
  --env ENV               test | prod (по умолчанию)
  --root PATH             доверенный корневой сертификат (можно несколько)
  --crl PATH              файл CRL (можно несколько)
  --ignore-truststore     [диагностика] цепочку строить только из сертификатов файла
  --document PATH         файл с подписываемыми данными (CONTAINER — detached-CMS)
  --online                дозапросить недостающие TSA-метку/OCSP-квитанцию живьём
                          (только НУЦ поколения GOST 2022 и BTS Digital) и проверить
                          дозаписанные данные из памяти, без записи на диск —
                          дозапрошенное помечается «(online)» в выводе
  --format FORMAT         text (по умолчанию) | json
  --lang ЯЗЫК             ru (по умолчанию) — язык вывода
  -v, --verbose           диагностика в stderr
  --version               показать версию и выйти
  -h, --help              показать эту справку и выйти
