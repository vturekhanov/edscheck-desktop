hash (Java) — хэш файла сертифицированной библиотекой KalkanCrypt (для информации, не проверка ЭЦП)

использование: hash [опции] <файл...|->

  -a, --algo ALGO   {{algo_list}} (по умолчанию {{default_algo}} = Streebog-512)
  -q, --quiet       краткий вывод '<hex>  <имя>' (как coreutils *sum), строка на файл
  --lang ЯЗЫК       ru (по умолчанию) — язык вывода
  -h, --help        показать эту справку и выйти

  файл              путь к файлу (любые байты, любой формат) или '-' (stdin);
                    можно несколько — по одному KalkanCrypt-провайдеру на весь вызов
