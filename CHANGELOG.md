# Changelog

Формат — по мотивам [Keep a Changelog](https://keepachangelog.com/); версии соответствуют `GuiVersion` (`src/gui/java/kz/edscheck/gui/GuiVersion.java`).

## [0.1.11] — 2026-07-17

Первый публичный срез исходников.

- Десктопное Swing-приложение (FlatLaf) поверх ядра проверки ЭЦП: выбор файла кнопкой/drag&drop, attached CMS и Карточки электронного документа PDF (`ddcard`) — сразу, detached CMS — автоопределение формата и запрос второго файла (документа). Панель ошибок, светлая/тёмная тема с автопереключением под системную.
- Сборка из исходников — macOS, Linux и Windows. Живая проверка с реальным окном — на macOS (arm64) и Windows (x64); на Linux (x64) подтверждена только сборка и запуск до попытки открыть окно (headless).
- Только исходники — платформенные бинарные сборки (macOS, Linux, Windows) в этот релиз не входят.
